
# Cross465 Runtime SDK — Runtime Template Specification (05)
[← 04: Display Module Scaffold](04_Cross465_Runtime_SDK_Display_Module_Scaffold_RetroModern2D.md) | [→ 06: asm465 Dev Loader](06_Cross465_Runtime_SDK_asm465_Dev_Loader_Spec.md)

**Status:** Draft • **Audience:** runtime builders • **Target:** desktop & WASM

Defines a **minimal static runtime** that selects modules and runs a **generated personality** (TOML→macro).

---

## 1. Goals
- **Static selection** of modules (Display/Audio/Input/System), no dynamic loading.
- **Embedded personality** generated by `cross465-pack` or `cross465-gen`.
- Optional **asset embedding** (desktop & WASM).
- Clean **error reporting** and predictable failure modes.

---

## 2. Project Layout (generated by packager)
```
myruntime/
 ├─ Cargo.toml
 └─ src/
    ├─ main.rs
    ├─ personality_gen.rs      # generated (TOML→macro)
    └─ assets.rs               # optional embedded assets
```

---

## 4. main.rs (template)
```rust
mod personality_gen; // emitted by codegen
use personality_gen::C64ModernPersonality;

use anyhow::Result;
use cross465_core::prelude::*;

fn main() -> Result<()> {
    let runtime = Runtime::builder()
        .with_display("RetroModern2D")
        .with_audio("BasicAudio")
        .with_input("GamepadInput")
        .with_system("BasicSystem")
        .with_personality(C64ModernPersonality)
        .build()?;
    runtime.run();
    Ok(())
}
```

## 5. WASM Entrypoint (optional)
```rust
// src/lib.rs (WASM target)
use wasm_bindgen::prelude::*;
mod personality_gen;
use personality_gen::C64ModernPersonality;
use cross465_core::prelude::*;

#[wasm_bindgen(start)]
pub fn start() -> Result<(), JsValue> {
    let runtime = Runtime::builder()
        .with_display("RetroModern2D")
        .with_audio("BasicAudio")
        .with_input("GamepadInput")
        .with_system("BasicSystem")
        .with_personality(C64ModernPersonality)
        .build()
        .map_err(|e| JsValue::from_str(&format!("init error: {e}")))?;
    runtime.run();
    Ok(())
}
```

---

## 6. Failure Modes
| Stage | Typical error | Handling |
|------:|----------------|----------|
| Module selection | Name not found / capability missing | Print message; list available modules. |
| Personality load | Generate/compile mismatch | Panic in dev; error in release with hint to rebuild. |
| Asset resolve | Missing asset id | Log error; render placeholder or fail fast. |
| WASM init | WebGL/Audio init failure | Return `JsValue` with reason. |

---

## 7. Integration with Packager
`cross465-pack` emits this template under `target/runtime/` and builds the binary with appropriate features.
